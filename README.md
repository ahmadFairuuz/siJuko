Aplikasi mobile resmi ekosistem **SiJuko** untuk Koperasi Mahasiswa Universitas Lampung (KOPMA Unila). Berhasil didistribusikan dan diadopsi oleh **71,8% anggota aktif di 1.040+ perangkat**.

---

## 🌟 Fitur Utama

- **Presensi & Absensi QR Code:** Fitur pemindaian QR code cepat dan fleksibel dengan integrasi galeri gambar.
- **Sistem Notifikasi Latar Belakang (FCM):** Integrasi Firebase Cloud Messaging untuk pengiriman pengumuman dan notifikasi transaksi secara _real-time_.
- **Viewer Laporan Keuangan:** Modul perjelajah PDF terintegrasi untuk transparansi laporan keuangan organisasi.
- **Sinkronisasi Data Anggota & Simpanan:** Pengolahan alur data simpanan dan profil anggota secara otomatis via REST APIs.

---

## 🛠️ Tech Stack & Dependencies

- **Framework:** Flutter (Dart)
- **State Management & Architecture:** Provider / BLoC
- **Services & Backend Integration:** REST APIs, Firebase Cloud Messaging (FCM)
- **Key Packages:** `qr_code_scanner`, `flutter_pdfview`, `image_picker`, `http`
